Kebijakan Privasi

Ingat Mantra (Penyihir vs Kucing) — Terakhir diperbarui: 26 November 2026

Ringkasan: Ingat Mantra tidak mengumpulkan, menyimpan, atau membagikan data pribadi kamu. Game berjalan sepenuhnya di perangkatmu.

1. Data yang Diproses Game

Game ini adalah Discord Activity yang berjalan di dalam aplikasi Discord. Saat kamu memainkannya:

  • Discord dapat menampilkan nama dan fotomu di dalam game (melalui otorisasi aplikasi Discord). Informasi ini hanya dipakai untuk ditampilkan selama kamu bermain dan tidak dikirim ke server milik pengembang — pengembang tidak mengoperasikan server yang menerima data tersebut.
  • Progres permainanmu (level, skor, boss yang dikalahkan) hanya tersimpan selama sesi bermain di perangkatmu dan hilang saat game ditutup.

2. Data yang Tidak Kami Kumpulkan

Kami tidak mengumpulkan, menyimpan, atau membagikan:

  • Nama, alamat email, nomor telepon, atau alamatmu.
  • Lokasi, daftar kontak, foto, atau file dari perangkatmu.
  • Data pelacakan, analitik, cookie, atau iklan. Game ini tidak memakai iklan dan tidak memakai layanan pelacak pihak ketiga.

3. Pihak Ketiga

File game di-host di GitHub Pages, dan game berjalan di platform Discord. GitHub dan Discord memiliki kebijakan privasi masing-masing yang mengatur data yang mereka proses sebagai penyedia layanan:

  • GitHub Pages — Kebijakan Privasi GitHub
  • Discord — Kebijakan Privasi Discord

4. Anak-anak

Game ini untuk khalayak umum dan tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak. Jika kamu di bawah umur, mainkan game ini dengan izin orang tua atau wali.

5. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Versi terbaru selalu tersedia di halaman ini.
