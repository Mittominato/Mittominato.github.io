Syarat Layanan

Ingat Mantra (Penyihir vs Kucing) — Terakhir diperbarui: 26 November 2026

Selamat datang di Ingat Mantra, game memori mantra yang dimainkan sebagai Discord Activity. Dengan memainkan game ini, kamu menyetujui Syarat Layanan berikut.

1. Tentang Game

Ingat Mantra adalah game gratis buatan Harith (Mittominato). Kamu berperan sebagai penyihir yang harus mengulang urutan mantra untuk mengalahkan kucing-kucing boss. Game berjalan di dalam Discord dan tidak memerlukan akun tambahan.

2. Penggunaan yang Diizinkan

Kamu boleh memainkan game ini untuk hiburan pribadi, membagikannya ke teman, dan memainkannya bersama di server Discord. Kamu tidak boleh:

  • Menggunakan cheat, bot, skrip, atau cara apa pun untuk memanipulasi skor, nyawa, atau progres game.
  • Menyalin, menjual, atau mengklaim game ini (atau aset-asetnya) sebagai milikmu.
  • Menggunakan game ini untuk tujuan yang melanggar hukum atau Ketentuan Layanan Discord.

3. Konten dan Kekayaan Intelektual

Seluruh aset game — gambar karakter, tombol permata, latar, dan video ultimate — adalah karya pengembang atau digunakan dengan izin. Discord dan logo Discord adalah milik Discord Inc. dan bukan bagian dari game ini.

4. Layanan Sebagaimana Adanya

Game disediakan "sebagaimana adanya" tanpa jaminan apa pun. Pengembang dapat memperbarui, mengubah, atau menghentikan game kapan saja, dan progres permainan (skor, level, boss yang dikalahkan) hanya tersimpan selama sesi bermain di perangkatmu dan dapat hilang sewaktu-waktu.

5. Batasan Tanggung Jawab

Sejauh diizinkan hukum, pengembang tidak bertanggung jawab atas kerugian apa pun yang timbul dari penggunaan game ini, termasuk kehilangan progres atau gangguan saat bermain.

6. Perubahan Syarat

Syarat ini dapat diperbarui sewaktu-waktu. Versi terbaru selalu tersedia di halaman ini. Dengan terus memainkan game setelah perubahan, kamu dianggap menyetujui syarat yang baru.
